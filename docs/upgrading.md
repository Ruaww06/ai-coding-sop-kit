## v3 项目接入 v4：复用证据，不重置状态

v4 加强的是需求与设计的判断、可观察的持久计划和全阶段反馈闭环，不要求重造所有既有材料：

- **先查评审证据。** 读取实际需求与设计、评审人、结论、待解决项及适用基线，确认必要调研、契约、验收与当前代码是否仍一致。有效且未受变化影响的评审直接复用；未评审、证据未知或关键假设变化的部分，补充对应评审，不自动通过，也不全量重做。已有需求文档不等于经过需求评审，已有设计不等于关键决定已通过评审。
- **保持独立责任。** 需求负责人确认业务意图，需求评审不能只由起草者自评完成；关键设计不能只由方案起草者自评通过，最终验收保留非实现者交叉检查。记录可以复用任务讨论，不强制会议或独立报告；换 AI、换会话或模型一致不能替代人的批准。
- **保留依赖与进度。** 复用已有任务系统或持久记录，关联任务、前序依赖、负责人、验收依据、验证方式与状态；多人、多依赖或跨会话工作保持持久计划，持续可见完成、在做、阻塞/回流与下一步责任。单一小任务可只用一条记录，不新建模板套装或任务数据库。
- **回流写回并关闭。** 需求、设计、实施、验收任何阶段发现问题，都保留证据并归因，交对应负责人裁决；更新需求/契约/设计等正式依据，同步受影响任务、文档及失效证据，按影响增量评审、实施与重验。仅记录问题不算解决；依据已更新、受影响实现与文档已调整、必要验证通过并获相应责任人确认后才关闭。
- **升级不重置业务状态。** 既有批准按原适用范围核对保留，不重复索取仍有效批准，也不扩大其授权。失败计数、同一问题连续两次修复失败的止损、HOLD、B/H/S 历史、未决回流与缺失验证不清零、不改写为通过；未知失败计数仍未知。必要检查失败和因条件缺失未执行必须区分。必要挂起项未清算，功能不能称完成。

安装工具包、采用 v4、批准实施和提交/合并/发布是不同授权。软件升级本身不启动业务开发，不补造评审、任务完成或验收结果；需要补评审时，仅暂停依赖未决判断的工作，不重做已有有效部分。

## 交给 Agent 的步骤

让 Agent 读取同一完整来源的 [INSTALL.md](../INSTALL.md) 和随技能分发的[英文升级指引](../skills/sop/references/upgrade.md)。只有旧安装、版本/形态切换或旧入口冲突才进入此分支，新项目不需要迁移仪式。

1. **只读盘点**：当前宿主、来源/版本及本地改动、适用项目入口和显式引用链、内嵌规则、定制、旧活动技能、真实任务与依赖/进度、评审及失败/验证历史。不读到的入口标未验证，不扫描整个主目录或擅自跟随越界链接；其他宿主副本只报告，不自动同步，不当作本宿主加载证据。
2. **完整预览**：列保留、替换、停用的文件和规则条款，标出未知/修改/混合来源与额外文件，说明权限、验证与恢复方式。复制安装要识别多余文件，不能整目录覆盖来替代迁移；独立 Git/插件副本优先用新完整来源，不 reset 修改过的副本。新技能组在发现路径外暂存，不往真实发现路径添加第二套活动技能，不把真实业务记录搬入可替换安装目录。
3. **获批切换**：先检查新来源完整可用，再按完整授权执行；安装授权不包含改规则、删除旧项或丢弃定制。关键冲突未裁决时在覆盖共享文件前停止，不静默过滤、不自动删除退役目录。若不能隔离验证新加载，先明确可恢复切换方案，保留旧入口于发现范围之外；未实测新加载仍报待验证，不以文件存在撤掉唯一可用入口。仍有效的授权不反复索取。
4. **逐项核验**：实际加载来源正确，六个预期技能及相对资源完整，退役技能不再被发现，活动引用没有断链，内嵌冲突已解决，定制/许可证/业务历史保留。文件安装、宿主加载和项目规则切换分开报告为未变、待核验、部分完成或已核验；全部适用检查有证据才称切换已核验。显式读取不能冒充原生发现，一次调用不能证明全组行为或业务验收。
5. **中断与重跑**：写入前重比现状；新改动与旧预览不一致时修订受影响项，不用旧授权覆盖新差异。中断后重读当前文件与有效授权，只继续剩余获批步骤；不清零、不自动回退覆盖新改动。已一致的步骤不重写，重复检查无差异应无操作。清理临时来源或移除安装另按适用授权，不删整个技能根目录、业务记录或其他副本。

此处不是自动迁移器，也不保证文件切换具有事务原子性；中途失败要保留实际状态与证据，停止受影响的业务执行，仅按已批准恢复方案处理。来源、加载或规则切换不明确时诚实保留待核验状态，不通过放宽权限、清缓存或另启模型掩盖限制。

## 验证与未来变化

历史版本的结构测试、升级样本及调用观察限于原版本、样本和宿主，见[验证说明](testing.md)。本轮文档更新未执行 v4 候选安装、加载、模型行为或迁移后业务测试；不能把历史通过结论换版本号沿用。来源比对和文件检查也不等于 Agent 能正确遵循新评审、计划与回流规则。

稳定入口为现有五技能加新增 `sop-requirements` 及安装指南；本次保留 common/upgrade 路径和相对资源，不承诺所有内部文件永久不变。未来结构变化须说明破坏性变更、来源与升级路径，继续核验权限、加载和历史保护，不为兼容长期并行加载两套冲突规则。发布修正使用新版本，不改写已发布标签；发布不等于真实宿主或业务行为已验收。
