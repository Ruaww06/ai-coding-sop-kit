## 交给 Agent 的步骤

让 Agent 读取同一完整来源的 [INSTALL.md](../INSTALL.md) 和随技能分发的[英文升级指引](../skills/sop/references/upgrade.md)。只有旧安装、版本/形态切换或旧入口冲突才进入此分支，新项目不需要迁移仪式。

1. **只读盘点**：当前宿主、来源/版本、适用项目入口及引用链、定制、旧活动技能、真实任务与失败/验证历史。不读到的入口标未验证，不扫描整个主目录或擅自跟随越界链接。
2. **完整预览**：列保留、替换、停用的文件和规则条款，说明授权、验证与恢复方式。复制安装要处理多余文件；独立 Git/插件副本优先用新完整来源，不 `reset` 修改过的副本。不往真实发现路径添加第二套活动技能。
3. **获批切换**：先检查新来源可用，再按完整授权执行；关键冲突未裁决时在覆盖共享文件前停止。若不能隔离验证新加载，先明确可恢复切换方案，保留旧入口于发现范围之外；未实测新加载仍报待验证，不以文件存在撤掉唯一可用入口。
4. **逐项核验**：实际加载来源正确，旧技能不再被发现，活动引用没有断链，内嵌冲突已解决，定制/许可证/历史保留。文件安装、宿主加载和项目规则切换分开报告；全部适用检查有证据才称切换已核验。
5. **中断与重跑**：重读现状和有效授权；新改动与旧预览不一致时只重新预览受影响项，不覆盖、不清零、不自动回退。已一致的步骤不重写，重复检查无差异应无操作。

此处不是自动迁移器，也不保证文件切换具有事务原子性；中途失败要保留实际状态、停止受影响的业务执行并按已批准恢复方案处理。

## 验证与未来变化

确定性测试使用真实发布 Git 内容复现覆盖残留、断链及跨路径旧入口保留，不代替 Agent 升级。两条受限 CLI 观察支持只读预览及能力不足时诚实停止。另一次人工审批的 v2 定制样本已独立核对文件切换、历史/定制保留和备份完整，原会话原生调用新版 `sop`、`sop-verification`，旧两入口探测不可用。本结论限于该样本及宿主；正常宿主存在后台网络、缓存与摘要请求，不能称完全隔离。授权拒绝、中断、恢复、重复升级及迁移后任务未实测，详见[验证说明](testing.md)。

稳定的使用入口是 `sop` 与安装指南，不承诺所有内部资源永久存在。未来结构变化应提供明确的破坏性变更说明和升级路径，核验实际来源、权限和历史保护；不为了兼容旧内部文件长期加载两套规则。发布修正用新版本，不改写已发布标签。
