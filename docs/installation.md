# 安装、更新与移除

SOP v3.1 / 包 `3.1.0-beta.1` 是 Beta 测试版。分发结构为五个技能与一份共享边界，旧模板和规则已移除。安装核验遇到多余活动 `sop-*` 技能或退役资源应停止，不能静默忽略或未经授权停用。

固定本版使用标签 `v3.1.0-beta.1` 的指南和完整源码；main 是移动的开发入口。先核对实际版本、commit 与内容；使用未提交副本还须说明本地改动。以下是接入说明，不代表安装已验收。

## 交给 Agent

让 Agent 阅读同一来源的 [INSTALL.md](../INSTALL.md)，确认当前宿主、目标项目、权限和接入方式后执行。公开 main 入口可以这样交给 Agent，实际版本以远端内容为准：

```text
请获取并遵循 https://raw.githubusercontent.com/Ruaww06/ai-coding-sop-kit/refs/heads/main/INSTALL.md，识别当前宿主，将 AI Coding SOP Kit 安装到当前项目；先核对实际版本，遇到冲突询问，不覆盖项目定制，也不自动开始业务开发。
```

需要固定本版时，让 Agent 读取 [v3.1.0-beta.1 安装指南](https://github.com/Ruaww06/ai-coding-sop-kit/blob/v3.1.0-beta.1/INSTALL.md)，并获取同标签完整源码。

Claude Code 的项目技能机制为 `.claude/skills/`，DeepSeek Harness 为 `.dsh/skills/`；项目根及当前 profile 先核实，其他宿主不猜目录。完整技能组同层，正文和共享资源单源。项目技能不带 Claude 插件命名空间或启动 hook。这些机制有资料依据，本候选的实际接入仍待验证。

安装前比较同名内容及已知活动入口，有冲突先询问；不改全局配置或权限，不覆盖业务规约和许可证。其他宿主副本只报告，不自动同步。安装不代表项目采用，业务实施、提交和发布另需相应授权。

## Claude Code 本地插件（可选）

需要已安装且可用的 Claude Code。在业务项目目录运行：

```sh
claude --plugin-dir "/absolute/path/to/ai-coding-sop-kit"
```

使用完整、已审阅工具包的绝对路径；路径有空格保留引号。此形态使用 `/ai-coding-sop-kit:sop`，项目技能则使用实际发现的 `/sop`。不未经确认并用两个入口；不提供 marketplace 安装。

hook 仅只读导航，不初始化项目、不运行检查、不批准操作，也不保证恢复或模型遵循。插件加载、技能调用和项目采用分别核验。

## 核验、更新与移除

安装后对照来源比较文件，实际调用入口并核对基目录及共享资源。未观察到原生加载时写“加载待验证”；必要时在同一项目新会话检查，不自动启动模型或绕过权限。显式读取成功不能冒充原生发现。

更新时使用经核实的新来源，先列差异、保留本地定制和项目任务/失败/未完成验证历史。需要改规约或停用旧入口须另获相应授权；不因更换技能把旧任务标为完成。不假定运行中缓存已更新。

移除项目技能前确认本次目录和本地修改，不删除整个技能根目录或项目记录。停止向新会话传 `--plugin-dir` 即停止加载该本地插件；不自动撤销其使用期间的项目改动。

发现、调用与行为证据的区别和未验证项见[测试说明](testing.md)。设计及外部参考见[设计依据](design.md)。
