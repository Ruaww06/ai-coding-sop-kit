# B / H / S 门禁

| 态 | 放行条件 | 唯一留痕位置 |
| --- | --- | --- |
| B 必经 | 不满足不放行，无豁免 | 对应阶段证据 |
| H 可挂起 | 仅物理上无法当场满足的现场、真机、外部环境验证；人判定后允许后续工作 | Known Issues；任务仅标 HOLD 并链接 |
| S 可跳过/降档 | 派发前由人按风险和类型判定，项目负责人确认 | 派发单记录判定人、理由及来源，档位回指计划 |

未标注视为 B。不得降级的五项护栏：至少三条可断言验收；oracle 独立于实现且 AI 不得自评通过；交叉验收人与实现者不同；入口停机义务；需求已指定必须实测的项目只能 B/H。AI 可起草 H/S 和档位建议，不能自行批准。

### 测试档位与证据

| 档位 | 风险 × 类型 | 最小测试集 |
| --- | --- | --- |
| 探索档 | 低风险 / 探索性 | 冒烟 + 关键断言 |
| 常规档 | 中风险 / 常规 | 单元 + 边界 + 反向用例 |
| 核心档 | 高风险 / 核心 | 全套适用测试 + 关键模块变异抽检 |

派发前由人判定、项目负责人确认，在计划中记录理由与真实来源。边界是待实测校准的经验起点；不能借降档跳过 B 或必测项。修 bug 先建立失败复现测试为 B；明确验收先落用例、重构先锁行为的强度按已批准档位执行。不可自动复现时报告阻塞并交人裁决，不自行豁免复现义务。

实现与独立验证短回路交替。断言预期来自需求、规格、外部真值、已知正确参考或不变量；禁止照抄实现。覆盖率、两个模型一致或 diff 相似不构成正确性证据。独立 runner 真实执行、记录命令/操作、结果和代码版本；代码再变重新验证。单元、契约、集成、系统/E2E、回归、非功能按档位及需求选择，真实依赖不能全用 mock 冒充。

本地可验项不绿不放行：档内用例与回归、oracle 溯源、关键分支、适用观测日志、文档同步、交叉验收。缺失、失败和未执行分开报告。自测、独立交叉验收、需求方验收分别保留真实来源；交叉验收不得由实现者或同一 AI 会话包办，最终验收由需求方确认。

项目检查入口还须扫描相对任务开始基线的新增路径，覆盖已暂存、未暂存和未跟踪文件（含临时目录），核对修改/删除路径白名单、禁止目录、忽略规则和依赖锁；相关忽略目录单独核查，不能把 Git 看不到当作不存在。Git diff 无法证明仓库外未写文件；需权限/审计补充，不能宣称全局强制。无 Git 时由项目提供等价基线与清单。工具包不附通用检查器，缺少检查能力须显式报告并补齐，不能用模型承诺充当硬门禁。
