# 执行与适配边界

本插件提供 SOP v2.0 的阶段技能、规则和模板。项目采用时需确认以下边界；遇到未接受的实质冲突停在相关决策处，不静默降低门禁。

- 项目规约采用含第 0 段的六段结构。插件无需把自身 AGENTS.md 复制给项目；项目规约仍须在授权内按六类职责补全，可复用已有入口。
- 五项不可降级护栏不意味着其他阶段门禁可降级；DoR、Design Freeze 和执行硬检查仍为 B。
- ADR 在冻结门禁为 B；可引用有效旧 ADR 或简短沿用记录，不能默默省略或推迟到冻结后补写。
- 非功能数值和验证计划先定义；H 挂起实际测量，不挂起设计文档。没有接口/持久化模型时明确其不存在及人评审依据，不造空文件。
- 小任务可引用已有有效记录，不能由 AI 以“小”为由省掉 B。S 仅按明确适用项由人判定。个人项目仍须安排独立验收，缺人不能自批。
- 四种任务状态和待派发备注按 [恢复规则](recovery.md) 记录。状态为“进行”不代表已经执行或已获授权；程序/模型不能从文件存在推断批准。
- 工具包不附跨语言的业务 check.sh。项目检查入口必须在相应授权内建立或复用；缺失检查能力写未完成，不靠空脚本或模型承诺通过。Git diff 不证明仓库外未写入。
- 插件要求复用、错误不掩盖、真实验证及受控改动；表达方式、视觉风格或脚本书写偏好不作为跨项目门禁。已有项目约定保留。
- SessionStart 只提供简短导航，不裁决是否采用全套流程；无 hook 的客户端通过显式入口或原生技能发现。加载后补报路由不等于第一条发言已受控制。
- CLI、任务数据库、定时周会、自动审批、CI 业务门禁、自动归档和多客户端自动安装均未实现。周窗口和 HOLD 计数是记录义务，需要项目实际执行。
- SOP 内容版本是 v2.0；当前插件包版本为 `2.0.0-beta.1`，由 plugin.json 登记。项目任务记录格式不因插件版本自动迁移。不得把内容更新称为发布或实际行为验收。

档位边界、HOLD 阈值仍待真实项目校准；外部最佳实践固定采集节奏仍待定。在完成相应验证前，不能把文档或结构检查当作插件行为证据。
